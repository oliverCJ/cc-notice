# Animation Files

Put transparent GIF files in this folder.

The downloaded template package intentionally does not include default GIF images. Add your own files with the names below, or update `manifest.json` to match your file names.

Required template files:

- `idle-sleep.gif`
- `task-wave.gif`
- `working.gif`
- `success.gif`
- `error.gif`

Optional template files:

- `idle-look-around.gif`
- `idle-thanks.gif`
- `task-cheer.gif`
- `task-fly.gif`
- `working-call.gif`
- `waiting-input.gif`
- `thinking.gif`
- `success-hug.gif`
- `warning.gif`

You can add more GIF files. Add each file to `manifest.json` under `animations`, then add one or more `actions` that reference the animation key.

Recommended GIF size: 240x240 to 512x512.
